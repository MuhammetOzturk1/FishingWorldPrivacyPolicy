Audience decision: teenagers and adults; not specifically directed to under-13 children. This is not an 18+ restriction or a claim that minors cannot download the game. The policy explicitly discloses that the app does not currently collect age and that AdMob may process data.

## Publish on GitHub Pages

1. Create a new PUBLIC repository named FishingWorldPrivacyPolicy under MuhammetOzturk1.
2. Upload only index.html from this folder to the repository root and commit it to main.
3. Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
4. Wait for the Pages deployment and open the generated HTTPS link to confirm it loads.
5. Use that verified link for both Fishing World apps in AdMob and the store privacy-policy fields.
